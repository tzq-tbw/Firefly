	目前大家的学习问题之一可能是琐碎凌乱的知识点无法储存到可视化、永久的仓库中，而知识库便是最好的笔记本。咱们先不做花里胡哨的笔记博客或动态笔记，先从最基本的开始：
	
#首先了解Obsidian的界面：
  1.下载Obsidian，登录谷歌账号，可以看到整个页面跟VSCode差不多，但是它出现的不是代码而是笔记文件夹![101.png](https://tian.tiandashuai.com/file/wenzhang/1785319381815_101.png)![102.png](https://tian.tiandashuai.com/file/wenzhang/1785319393349_102.png)
  2.Obsidian内部有很多插件，当然你也可以自己做，之后让agent自动上传到你的Obsidian中。插件的功能有非常多，大家可以自行浏览或者上网查询，我主要是下了几个跟发布博客有关的插件，大家如果只是做知识库其实没有什么插件可以下。
#接着是具体的知识库记录方法为： 
  1.在Edge浏览器的拓展中搜索Obsidian，里面有官方插件，这个插件的功能是自动抓取视频中的内容并总结成要点，你需要自己配置API，还有笔记格式，这个大家可以上网去搜，然后记录的笔记会自动传入到你的知识库中。
  2.让你的 Agent 自动识别抖音、快手或 B 站的视频链接，并执行以下操作：
  提取文字并做出总结；整理出一份 Markdown 文件；连接到你的知识库中自动储存。
  具体的提示词如下：
  帮我构建一个 skill，具体步骤如下：

1. 当我发给你链接时，用 videodl 解析链接并提取出视频。
2. 使用 ffmpeg 提取出视频的音频。
3. 使用 faster-whisper 提取出逐字稿。
4. 对逐字稿进行分段式总结，做成一篇 markdown 格式的笔记。
5. 笔记中的文字只保留你总结的部分，不要视频的文字信息与逐字稿原文。
6. 把文档存入我的知识库地址。
7. 大家将今日的知识库补充之后可以加一句：按照wiki排版法重构我的知识库。
  目前这就是最基础的知识库构建方式，在之后还有知识库可视化看板、自动更新的知识库等等，待我过几天再发。
